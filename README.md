Blockchain-Based Identity Management Framework with MFA

📌 Project Overview

This project presents a Blockchain-Based Identity Management Framework with Multi-Factor Authentication (MFA) designed to provide self-sovereign, secure, and user-centric digital identity management. The system leverages blockchain technology, Web3 authentication, and OTP-based MFA to overcome the limitations of traditional centralized identity systems.

🚀 Key Features

Self-Sovereign Identity using blockchain

MetaMask-based Web3 authentication

OTP-based Multi-Factor Authentication

Hash-based on-chain identity storage

Off-chain credential handling

Downloadable identity verification proof

🛠️ Tech Stack

Solidity, Ethereum / Polygon

MetaMask (Web3 Wallet)

React.js (Frontend)

Node.js & Express (Backend)

MongoDB (Database)
